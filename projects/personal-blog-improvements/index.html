Portfolio & Blog Improvements

March 7, 2026 · Kaung Htet Ko

HTML, CSS, JavaScript

Overview

This portfolio site is an ongoing project. I continuously improve its structure, readability, and user experience. It's built with vanilla HTML, CSS, and JavaScript — no frameworks, no build tools. Just the web platform.

Why Vanilla?

I chose to build this without React, Next.js, or any framework for a few reasons:

  • Full control over every pixel and interaction
  • No build step — push to GitHub Pages and it's live
  • Deepens understanding of how the web actually works
  • Keeps the site fast and lightweight

What I've Improved

  • Semantic HTML structure for better accessibility and SEO
  • Responsive design that works well on mobile, tablet, and desktop
  • Dynamic content loading from JSON files for blog posts and projects
  • Clean typography system with Google Fonts
  • Dark theme with consistent color variables
  • Smooth scroll animations using IntersectionObserver

Key Takeaways

  • CSS custom properties make theming and maintenance much easier
  • Vanilla JS is more than enough for a portfolio site
  • Performance matters — this site scores 100 on Lighthouse
  • Writing HTML by hand forces you to think about structure and semantics
